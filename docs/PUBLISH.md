# Publishing to GitHub

Repository: `https://github.com/akalh233-bot/linear-baseline.git`

The local repository is initialised on branch `main`, fully committed, and
`origin` is already configured. The only missing piece is the **empty remote
repository**, which does not exist yet (the account `akalh233-bot` has no
`linear-baseline` repo at the time of writing).

## Step 1 — create the empty repo (one click)

Open <https://github.com/new> and create:

| field | value |
| --- | --- |
| Repository name | `linear-baseline` |
| Visibility | Public (or Private) |
| Initialize with README | **off** |
| Add .gitignore | **off** |
| Choose a license | **off** |

An initialised remote would conflict with the local commit, so all three
"initialize" boxes must stay unchecked.

## Step 2 — push

```powershell
cd E:\triomics\linear-baseline
git push -u origin main
```

Git Credential Manager will ask you to sign in to GitHub the first time (a
browser window; the `akalh233-bot` account). After that the credential is cached
and later pushes are silent.

If the push fails with `remote: Repository not found`, the repo was not created
under exactly that name/account; check the URL with `git remote -v`.

## Step 3 — recommend settings

| field | value |
