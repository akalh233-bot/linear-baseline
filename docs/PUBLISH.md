## Step 1 — push

```powershell
cd E:\triomics\linear-baseline
git push -u origin main
```

Git Credential Manager will ask you to sign in as `akalh233-bot` the first time
(a browser window). After that the credential is cached and later pushes are
silent. If the push fails with `remote: Repository not found`, check
`git remote -v` — the remote must be exactly the URL above.
